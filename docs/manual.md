# 簡易マニュアル

メモ帳アプリ（WAKIASEMEMO）の使い方です。
アプリの起動方法や開発のしかたは、リポジトリ直下の `readme.md` を見てください。

## 1. アプリを開く

1. コンテナを起動する（初めてのときは `readme.md` の「はじめて動かすとき」を先に行う）

   ```powershell
   docker compose up -d
   ```

2. ブラウザで http://localhost:3000/ を開く

使い終わったら `docker compose down` で停止します。停止してもメモは消えません。

## 2. 画面の見かた

画面は、左の **メモ一覧** と、右の **エディタ（ノートのページ）** に分かれています。
画面の幅が狭いとき（スマートフォンなど）は、一覧が上、エディタが下に並びます。

```text
┌───────────────┬──────────────────────────────────┐
│ メモ一覧      │ No. 3          Date 2026 . 11 . 17 │
│ [＋ 新規]     │ タイトル                           │
│ 並び替え [▼]  │ ─────────────────────────────── │
│               │ 本文                               │
│ ・買い物      │                                    │
│ ・会議メモ    │                                    │
│ ・...         │                                    │
│               ├──────────────────────────────────┤
│               │ 未保存  ステータス   [削除] [保存] │
└───────────────┴──────────────────────────────────┘
```

| 場所 | 内容 |
|---|---|
| ＋ 新規 | 新しいメモを書き始める |
| 並び替え | 一覧の並び順を選ぶ |
| メモ一覧 | 保存したメモのタイトルと更新日時。押すとエディタに開く |
| No. / Date | 開いているメモの番号と登録日（新しいメモのときは空欄） |
| タイトル・本文 | メモを書く欄 |
| 未保存 | 保存していない変更があるときだけ表示される |
| ステータス | 「保存しました」などの結果や、ほかの画面での変更のお知らせ |
| 削除・保存 | 開いているメモを削除する・保存する |

## 3. 基本の操作

### メモを作る

1. 「＋ 新規」を押す（ページがめくれて白紙のページになる）
2. タイトルと本文を書く
3. 「保存」を押す（または `Ctrl` + `S`、Mac は `⌘` + `S`）

ステータスに「作成しました」と出て、一覧にメモが追加されます。

- **タイトルを空のまま保存すると**、「メモ(2026-11-17)」のように、その日の日付がタイトルに入ります。
- 本文は空のままでも保存できます。

### メモを開く・直す

1. 一覧のメモを押すと、エディタに開く
2. 内容を書き直して「保存」を押す

ステータスに「保存しました」と出て、一覧のいちばん上（更新日時の新しい順のとき）に移ります。

### メモを削除する

1. 一覧から削除したいメモを開く
2. 「削除」を押し、確認で「OK」を押す

- 削除したメモは、画面から元に戻せません。
- 新しいメモを書いているとき（まだ一度も保存していないとき）は、「削除」は押せません。

### 一覧を並び替える

「並び替え」で次の6つから選べます。

| 並び順 |
|---|
| 更新日時（新しい順）※最初はこれ |
| 更新日時（古い順） |
| 登録日時（新しい順） |
| 登録日時（古い順） |
| タイトル（昇順） |
| タイトル（降順） |

並び替えの選択は、画面を読み込み直すと「更新日時（新しい順）」に戻ります。

## 4. 書いている途中の内容を守るしくみ

### 保存していない変更があるとき

保存していない変更（「未保存」の表示が出ている状態）があるまま、次の操作をすると確認が出ます。

| 操作 | 出る確認 |
|---|---|
| 「＋ 新規」を押す、一覧の別のメモを押す | 「保存していない変更があります。破棄しますか？」 |
| タブを閉じる、ページを再読み込みする | ブラウザの「このサイトを離れますか？」 |

「キャンセル」を押すと、そのまま書き続けられます。

### 下書きの復元

書いている途中の内容は、ブラウザに **下書き** として自動で残ります。
タブを閉じたり、ブラウザが落ちたりしても、次に開いたときに「保存していない下書きがあります。復元しますか？」と聞かれます。

- 「OK」：書きかけの内容がエディタに戻る。まだ保存されていないので、「保存」を押して保存する
- 「キャンセル」：下書きを捨てる

下書きは、使っているブラウザの中にだけ残ります。別のブラウザや別のパソコンでは復元できません。
また、プライベートブラウズ（シークレットモード）では下書きが残らないことがあります。

## 5. 複数のタブ・パソコンで使うとき

同じアプリを複数のタブやパソコンで開いていると、ほかの画面での作成・変更・削除が、自動で一覧に反映されます。

| ほかの画面で起きたこと | この画面の動き |
|---|---|
| 開いているメモが変更された（こちらは未変更） | 新しい内容に切り替わる |
| 開いているメモが変更された（こちらも書きかけ） | 書きかけの内容は消えない。保存すると、こちらの内容で上書きする |
| 開いているメモが削除された（こちらは未変更） | エディタが新しいメモの状態になる |
| 開いているメモが削除された（こちらも書きかけ） | 書きかけの内容は消えない。保存すると、新しいメモとして作成する |

同じメモを2か所で直したときは、**あとから保存した方の内容が残ります**。

### サーバーとの接続が切れたとき

ステータスに「サーバーとの接続が切れました。再接続しています…」と出ます。
自動でつなぎ直し、つながると「再接続しました」と出て、一覧が最新の状態になります。
接続が切れている間も、書くこと自体はできます。

## 6. 入力できる量

| 項目 | 上限 |
|---|---|
| タイトル | 100文字 |
| 本文 | 10,000文字 |

上限まで書くと、それ以上は入力できません。

## 7. 困ったとき

| 症状 | 確認すること |
|---|---|
| 画面が開かない | コンテナが動いているか（`docker compose ps`）。起動直後はパッケージのインストール中なので、`docker compose logs -f app` で `Server running at http://localhost:3000` が出るまで待つ |
| 「一覧を取得できませんでした」と出る | MySQL のコンテナが動いているか。テーブルを作ったか（`readme.md` の「はじめて動かすとき」の 3） |
| 「保存できませんでした」と出る | メッセージの内容を確認する。接続が切れているときは、再接続を待ってからもう一度保存する |
| 「このメモはほかの画面で削除されていました」と出る | 書いた内容は残っている。もう一度「保存」を押すと、新しいメモとして保存される |
